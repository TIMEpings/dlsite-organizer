# DLsite Organizer v1.5.0

下载 Windows x64 便携包 **`dlsite-organizer-1.5.0-windows-x64.zip`**，解压完整目录后运行 `dlsite-organizer.exe`。升级前建议备份现有配置和 SQLite 数据库；新版会在现有数据库中补充特典证据字段。如果移动了便携目录，请在设置中显式更新 Explorer 右键菜单注册。

### 新功能与改进

- **期限特典发现**：主动查找活动特典和历史候选，可从本体打开特典，也可从特典返回本体。活动仍有效且标题、社团、登记日期等证据交叉吻合时，可自动保存高置信关联。候选可人工确认、拒绝或退回待审，人工判断优先。
- **RJ 范围与续查**：使用非线性滑块或自定义正负偏移选择范围，分段继续查找。优先使用本地证据及仍有效的缓存，保留已筛查结果。
- **查询体验**：新增翻译语言版本发现、查询历史前进／后退；改进元数据和封面缓存，扫描可补充普通查询缓存，不覆盖普通查询写入的条目。
- **Windows 快速重命名**：可在设置中选择 Explorer 右键触发重命名后是否自动唤醒轻量窗口；改进原生 Helper 回执、单实例命令和持久化请求处理，以及退出和窗口切换的稳定性。

### 搜索限制

特典发现依赖 DLsite 的非公开 AJAX 接口，接口可能变更。每次搜索至多发起 1 次本体查询、5 次优先候选查询；maniax 范围搜索最多 20 批，每批至多 5 个 RJ，串行发送，批请求开始时间至少间隔 10 秒，4 分钟后不再发起新的范围请求。接口错误可能提前结束范围搜索。

历史特典可能已不再公开展示，也可能无法从 AJAX 取得。未找到不代表从未存在。范围覆盖数字来自离线样本，只供选择范围参考；它不是实际发现率。高置信关联由应用根据证据推断，并非 DLsite 官方确认。

Windows 发行包中的 EXE 未做 Authenticode 签名。
